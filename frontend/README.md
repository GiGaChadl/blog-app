# Nhật Ký Của Tôi — Blog cá nhân (Public Site)

👉 Đọc **`TOM-TAT-NHANH.md`** trước tiên để nắm toàn bộ bối cảnh dự án trong 2 phút.

Sau đó xem thêm:
- `HUONG-DAN-CHI-TIET.md` — hướng dẫn kỹ thuật đầy đủ (thiết kế, dark mode, danh mục 3 cấp, luồng OTP, kích thước ảnh, cách nối API thật, SSR...)
- `CHANGELOG.md` — lịch sử các thay đổi theo từng đợt góp ý

## Chạy nhanh

```bash
npm install
npm start
```

Mở `http://localhost:4200`.
